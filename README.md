# Sweet — Gourmet Food Web Application

**Sweet** is a modern, responsive food ordering application built with a **Midnight Luxury / Dark Mode** visual identity[cite: 2, 3]. Designed with glassmorphism aesthetics, warm amber highlights, and intuitive UI components, Sweet offers an effortless platform to browse gourmet items, track orders, and manage user preferences[cite: 1, 2].

---

## ✨ Features

- **Gourmet Food Cards & Showcase:** High-definition menu items complete with ratings, badges, and quick-add actions[cite: 1].
- **Interactive User Dashboard:** Tabbed navigation interface allowing users to view profiles, order histories, live messages, and app settings.
- **Authentication Flows:** Clean, responsive **Sign In** and **Sign Up** screens with background blur overlays and subtle lighting effects.
- **Glassmorphic UI Elements:** Built using translucent dark panels (`bg-zinc-900/80`), backdrop blur (`backdrop-blur-md`), and glowing amber accents (`text-amber-400`)[cite: 1, 2].
- **Fully Responsive:** Seamlessly adapts across mobile, tablet, and desktop viewports[cite: 3].

---

## 🛠️ Tech Stack

- **Frontend Framework:** [React.js](https://react.dev/)[cite: 2]
- **Styling & Design System:** [Tailwind CSS](https://tailwindcss.com/)[cite: 2]
- **Icons:** [Lucide React](https://lucide.dev/)
